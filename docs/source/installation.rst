Installation
============

Requirements
------------
* Python >= 3.10
* Virtual environment (recommended: ``.venv``)

Install from Source
-------------------
Clone the local repository and install in editable mode:

.. code-block:: bash

   cd /path/to/AUTEX
   python3 -m venv .venv
   source .venv/bin/activate
   pip install --upgrade pip
   pip install -e .
