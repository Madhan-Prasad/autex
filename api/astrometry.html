autex.astrometry.build_wcs_header(ra_center_deg, dec_center_deg, pixel_scale_arcsec=0.307, rotation_deg=0.0, crpix=(512.5, 512.5))[source]

Generate a standard FITS TAN World Coordinate System object.

Parameters:

  • ra_center_deg (float) – Right Ascension of detector reference center (deg).

  • dec_center_deg (float) – Declination of detector reference center (deg).

  • pixel_scale_arcsec (float) – Plate scale in arcsec/pixel (TIRSPEC default is ~0.307 arcsec/pix), by default 0.307.

  • rotation_deg (float) – Position angle east of north (degrees), by default 0.0.

  • crpix (tuple[float, float]) – Pixel coordinate of the reference point (X, Y), by default (512.5, 512.5).

Returns:

Astrometric WCS mapping pixels to sky coordinates.

Return type:

WCS

Match brightest star triangles between image and catalog to solve for coordinates and rotation.

Parameters:

  • detected_sources (list[SourceDetection]) – Detected stars on the image.

  • catalog_stars (list[dict[str, Any]]) – Catalog reference stars from 2MASS.

  • pixel_scale_arcsec (float) – Plate scale, by default 0.307.

  • tolerance (float) – Fractional side-ratio tolerance for matching triangles, by default 0.02.

Returns:

Solved (ra_center, dec_center, rotation_deg), or None if match fails.
