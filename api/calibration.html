Calibration Engine (autex.calibration)

Detector calibration, SUTR bias relaxation modeling, and slope fitting for autex.

autex.calibration.assemble_quadrants(q1, q2, q3, q4)[source]

Recombine four 512x512 quadrants back into a 1024x1024 array or cube.

Parameters:

  • q1 (ndarray) – Individual amplifier quadrants.

  • q2 (ndarray) – Individual amplifier quadrants.

  • q3 (ndarray) – Individual amplifier quadrants.

  • q4 (ndarray) – Individual amplifier quadrants.

Returns:

Reconstructed 1024x1024 array or 3D cube.

Return type:

ndarray

autex.calibration.fit_sutr_slope(cube, fit_slice=None, time_array=None)[source]

Perform vectorized linear least-squares regression along the temporal axis.

Calculates flux count rate (beta, ADU/frame) and intercept (alpha) for every pixel.

Parameters:

  • cube (ndarray) – 3D SUTR cube of shape (Nframes, Ny, Nx).

  • fit_slice (slice | None) – Frame index slice to fit across. Defaults to omitting the reset transient.

  • time_array (ndarray | None) – Optional explicit time timestamps. Defaults to frame indices.

Returns:

(slope_map, intercept_map) each of shape (Ny, Nx).

Return type:

tuple[ndarray, ndarray]

autex.calibration.interpolate_row_clock_delays(master_1d_curve, num_rows=512, extrapolate=True)[source]

Resample master decay curve across sequential row-clock delay offsets.

Parameters:

  • master_1d_curve (ndarray) – 1D temporal array representing master decay profile across frames (length N).

  • num_rows (int) – Number of physical detector rows per amplifier channel, by default 512.

  • extrapolate (bool) – Whether to extrapolate boundary frames, by default True.

Returns:

2D array of shape (Nframes, num_rows) with row-specific time delays.

Return type:

ndarray

autex.calibration.remove_pedestal(cube)[source]

Subtract the initial reset frame (D0) from all SUTR readout frames.

Parameters:

cube (ndarray) – 3D array of shape (Nframes, Ny, Nx).

Returns:

Pedestal-subtracted cube with frame 0 zeroed out.

Return type:

ndarray

autex.calibration.split_quadrants(frame_or_cube)[source]

Slice a 1024x1024 detector array into its four 512x512 amplifier quadrants.

Layout:

Q1 (Bottom-Left) : [0:512, 0:512] Q2 (Top-Left) : [512:1024, 0:512] Q3 (Bottom-Right): [0:512, 512:1024] Q4 (Top-Right) : [512:1024, 512:1024]

Parameters:

frame_or_cube (ndarray) – 2D image (1024, 1024) or 3D cube (Nframes, 1024, 1024).

Returns:

List containing [Q1, Q2, Q3, Q4].

Return type:

list[ndarray]
