autex.spectroscopy.correct_telluric_absorption(science_spectrum, standard_spectrum, standard_bb_temperature=9500.0, wavelengths=None)[source]

Correct for telluric absorption features by dividing by a telluric standard star.

Parameters:

  • science_spectrum (ndarray) – Extracted 1D target spectrum.

  • standard_spectrum (ndarray) – Extracted 1D telluric standard star spectrum (observed at similar airmass).

  • standard_bb_temperature (float) – Standard star effective blackbody temperature (A0V standard is ~9500 K), by default 9500.0.

  • wavelengths (ndarray | None) – Wavelength array in micrometers for continuum shaping, by default None.

Returns:

Telluric-corrected, continuum-normalized science spectrum.

Return type:

ndarray

autex.spectroscopy.extract_optimal_spectrum(image, y_trace, variance_map=None, aperture_radius=6, gain=4.5, read_noise=15.0)[source]

Extract 1D spectrum using spatial profile weighting (Horne’s Algorithm).

Parameters:

  • image (ndarray) – Calibrated 2D frame.

  • y_trace (ndarray) – Trace spatial center coordinate Y for each column X (length Nx).

  • variance_map (ndarray | None) – Precomputed variance map. If None, derived from gain and read noise.

  • aperture_radius (int) – Spatial half-width for extraction profile, by default 6 pixels.

  • gain (float) – Detector gain (e-/ADU), by default 4.5.

  • read_noise (float) – Read noise (e-), by default 15.0.

Returns:

(flux_1d, flux_err_1d) across dispersion columns.

Return type:

tuple[ndarray, ndarray]

autex.spectroscopy.fit_spectral_trace(diff_image, search_window_y=None, poly_order=2, bin_width=32)[source]

Locate and trace the stellar continuum centroid along the dispersion axis.

Parameters:

  • diff_image (ndarray) – 2D difference frame (A - B). Dispersion axis is horizontal (X), spatial is vertical (Y).

  • search_window_y (tuple[int, int] | None) – (ymin, ymax) pixel boundaries to isolate positive trace A, by default None.

  • poly_order (int) – Polynomial degree for trace curvature model, by default 2.

  • bin_width (int) – Column binning width along dispersion axis to increase SNR, by default 32.

Returns:

Trace center Y-pixel coordinate for every dispersion column X. Shape: (Nx,).

Return type:

ndarray
